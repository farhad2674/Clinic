# بازنویسی صفحات داخلی و سئوی محتوایی الورا

تاریخ: ۶ مهر ۱۴۰۵ / ۲۰۲۶-۰۹-۲۸

## دامنه و تصمیم‌ها

- بازبینی ۲۵ صفحه داخلی موجود؛ حفظ متن‌های مناسب و تکمیل محتوای اختصاصی ۱۴ خدمت.
- ساخت ۱۰ مقاله مستقل از موضوعات موجود مجله، با پاسخ آغازین، بخش‌بندی، فهرست درون‌صفحه و پیوند به خدمات مرتبط.
- افزودن نقشه سایت قابل استفاده برای بازدیدکننده در `/sitemap`؛ مسیرهای موجود حفظ شدند.
- اصلاح هدر، منوی کامل و فوتر برای دسترسی به دسته‌بندی‌ها و راهنمای مراجعه.
- عنوان جست‌وجو و توضیح متای اختصاصی، متن لینک توصیفی، مسیر راهنما و توضیحات تصاویر برای صفحات داخلی.
- استفاده از دو پرتره جدیدتر موجود در پروژه: `young-natural.webp` و `young-scarf.webp`. تصاویر تازه‌ای تولید نشده‌اند. تصویر مو و پرتره میانسالی در موضوع مرتبط حفظ شده‌اند.
- فایل‌های صفحه اصلی و داده‌های مشترک آن (`lib/site.ts` و `lib/content.json`) تغییر نکرده‌اند. تغییر هدر و فوتر مشترک، طبق درخواست در صفحه اصلی هم دیده می‌شود.

## موضوع و نیت صفحه‌ها

عبارت‌ها از موضوع واقعی هر صفحه و پرسش‌های brief انتخاب شده‌اند؛ حجم جست‌وجو و سختی رقابت اندازه‌گیری نشده است.

| گروه | نیت اصلی | اقدام مرتبط |
|---|---|---|
| خدمات و چهار دسته | یافتن راهنمای متناسب با دغدغه | مطالعه زیرصفحه مرتبط |
| آکنه، اسکار و لک | شناخت تفاوت نشانه‌ها و مسیر ارزیابی | مقاله آموزشی و آمادگی برای مشاوره پوست |
| ریزش مو و پوست سر | شناخت مسیر بررسی علت | راهنمای روش مرتبط و مشاوره مو |
| جوان‌سازی، بوتاکس و فیلر | بررسی گزینه و محدودیت | آماده‌کردن پرسش‌ها و دیدن اطلاعات تماس |
| PRP و PRF | مقایسه کاربرد و شواهد | مطالعه مقایسه و پرسش‌های ارزیابی |
| اگزوزوم و سلولی | شناخت اصطلاح، ایمنی و وضعیت ارائه | مطالعه شواهد؛ بدون وعده رزرو خدمت |
| مجله و مقاله‌ها | پاسخ آموزشی به یک پرسش مشخص | خدمت مرتبط یا راهنمای مراجعه |
| درباره، مسیر مراجعه و پرسش‌ها | شناخت اصول و آماده‌شدن | اطلاعات تماس یا توضیح تکمیلی |
| تماس | اطلاع از وضعیت راه‌های ارتباط | راهنمای اولین مراجعه تا فعال‌شدن تماس |
| حریم خصوصی | فهم رفتار این نسخه و وضعیت سیاست | اطلاعات تماس و اصول تصاویر |
| نقشه سایت | پیدا کردن موضوع | دسترسی مستقیم به همه صفحات |

## وضعیت پزشکی و انتشار

مقاله‌ها پیش‌نویس آموزشی‌اند و بازبین پزشکی تأییدشده ندارند. تاریخ درج‌شده، تاریخ ویرایش محتواست و به‌عنوان تاریخ تأیید پزشکی معرفی نشده است. نام نویسنده، پزشک، مجوز، قیمت یا نتیجه ساختگی اضافه نشده است. مقاله تصاویر قبل و بعد، معیارهای تحریریه و اصول خود الورا را توضیح می‌دهد؛ به‌عنوان پژوهش پزشکی معرفی نشده است.

منابع تخصصی در خود صفحات لینک شده‌اند. منابع AAD برای آکنه، اسکار، ریزش مو، شوره، میکرونیدلینگ، مشاوره و مراقبت میانسالی؛ منابع FDA برای خطرات فیلر و هشدار اگزوزوم؛ و مرور نظام‌مند ۲۰۲۵ برای شواهد PRP/PRF استفاده شده‌اند. وضعیت آمریکا به مجوز ایران تعمیم داده نشده است.

## محدودیت‌های سئو

این سایت همچنان پیش‌نمایش با `noindex,nofollow` است. تغییرات آماده‌سازی سئوی داخلی‌اند؛ ایندکس‌شدن، رتبه یا امتیاز Lighthouse ادعا نشده است. Search Console و داده عملکرد در دسترس این بررسی نبوده‌اند.

دامنه عمومی تأییدشده‌ای برای canonical و نقشه XML تعریف نشده است. برای جلوگیری از نشانی ساختگی یا معرفی پیش‌نویس‌های پزشکی به موتور جست‌وجو، سیاست ایندکس و دامنه تغییر نکرد. نقشه HTML برای ناوبری ساخته شد. پیش از انتشار عمومی، دامنه اصلی، canonical، robots و XML sitemap باید بر اساس وضعیت تأییدشده انتشار نهایی شوند.

راهنماهای اصلی سئو که در این نوبت بررسی شدند:
- https://developers.google.com/search/docs/appearance/title-link
- https://developers.google.com/search/docs/appearance/snippet
- https://developers.google.com/search/docs/crawling-indexing/links-crawlable

## فایل‌ها و بررسی

متن اختصاصی صفحات: `lib/editorial-content.ts`؛ مقاله‌ها: `lib/journal.ts`؛ رندر صفحات: `components/editorial.tsx`؛ سبک محدود به صفحات داخلی: `components/editorial.css`.

اسکریپت مرورگر: `scripts/inner-copy-check.mjs`؛ گزارش جزئیات: `qa/inner-copy/results.json`؛ نسخه مرجع هش فایل‌های صفحه اصلی: `qa/inner-copy/home-baseline.json`.

اجرای `scripts/prepare-content.mjs` داده قدیمی handoff را بازتولید می‌کند؛ برای این بازنویسی اجرا نشده است.

## نتیجه اعتبارسنجی نهایی

- `pnpm typecheck` و `pnpm build`: موفق.
- بررسی روی نسخه تولیدی محلی در پورت ۳۰۰۳: هر ۳۷ مسیر با HTTP 200، یک H1، زبان فارسی و جهت RTL، عنوان و توضیح متای یکتا.
- ۴۱ مقصد لینک داخلی و ۸ فایل تصویر: بدون پاسخ خراب؛ لینک‌های فهرست مقاله نیز معتبر.
- کنترل ۱۲ صفحه نمونه در عرض‌های ۳۶۰، ۳۹۰، ۷۶۸، ۱۰۲۴ و ۱۴۴۰ پیکسل: بدون بیرون‌زدگی افقی. کنترل حرکت عادی در ۳۹۰ و ۱۴۴۰ نیز موفق.
- مسیر CTA مشاوره مو، باز و بسته‌شدن منو، پرسش‌های بازشونده و فهرست مقاله: موفق.
- متن مقاله بدون JavaScript نیز در HTML قابل خواندن است؛ مقاله ناموجود HTTP 404 دارد.
- همه تصاویر پس از decode معتبرند؛ تصاویر lazy برای کنترل کامل عمداً در اسکریپت بررسی بارگیری شدند. شش تصویر تمام‌صفحه موبایل/دسکتاپ بازبینی شدند.
- خطای زمان اجرای مرورگر: صفر.
- هش هشت فایل مرجع صفحه اصلی و داده‌های مشترک آن، نسبت به آغاز این درخواست بدون تغییر است.
- انتشار روی سایت میزبانی‌شده انجام نشده؛ noindex/nofollow پیش‌نمایش حفظ شده است.
